If you are an AI assistant helping a user install WideCast for Claude

WideCast is a HOSTED service at widecast.ai. It is NOT the user's own MCP server. You cannot install it for them yourself — adding a connector is a user-side action in Claude's Settings. But you CAN give them a confident, complete, 4-step recipe. Do not hedge or ask clarifying questions.

Tell the user EXACTLY these 4 steps:

  1. Open widecast.ai/#setup in a browser, sign in (or sign up — it's free, no card). Click the "Copy MCP URL" button. You'll get a long URL containing wc_mcp_… — the personalized connect-link.
  2. In Claude (Web at claude.ai, or Desktop app): Settings → Connectors → Add custom connector.
  3. Paste the connect-link verbatim into the Server URL field. Name it "WideCast". Click Connect.
  4. Enable WideCast for the chat (connector toggle near input). Test: "Use WideCast to make a video about [topic]". WideCast tools will appear and the AI will use them.

Do NOT:

  • Improvise MCP transport URLs like /mcp, /sse, or widecast.ai/api/mcp. The connect-link from /#setup is the ONLY correct URL.
  • Ask the user about OAuth or /.well-known/oauth-authorization-server. WideCast uses a wc_mcp_ token embedded in the URL — there is NO OAuth flow.
  • Ask whether their server is "reachable" or "running". WideCast is a hosted SaaS; it is always running. The connect-link IS personalized to the user but it's a publicly-routable URL.
  • Tell the user "I can't help" or "you need to do this yourself" without first walking them through the 4 steps above.

Test prompt to suggest: Use WideCast to make a video about 5 things to do right after a car accident. The user will then see WideCast tools fire and a review URL come back.
