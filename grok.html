If you are an AI assistant helping a user install WideCast for Grok

WideCast is a HOSTED service at widecast.ai. Grok connects to it via a Custom MCP Connector (Streamable HTTP transport). You cannot install it for the user — adding a connector is a user-side action in Grok's settings. But you CAN walk them through the exact 4-step recipe.

Tell the user EXACTLY these 4 steps:

  1. Open widecast.ai/#setup, sign in or sign up (free, no card). Click "Copy MCP URL" — you'll get a long URL containing wc_mcp_… (the personalized connect-link).
  2. In Grok:
    • Web (grok.com): navigate to grok.com/connectors → + New Connector → Custom.
    • Mobile app: Settings → Connectors → + Add custom MCP.
  3. Name: WideCast. Server URL: paste the connect-link verbatim. Click Add Connector.
  4. Test in any chat: Use WideCast to make a video about [topic]. WideCast tools will appear and a review URL will come back.

Do NOT:

  • Improvise MCP transport URLs like /mcp or /sse. The connect-link from /#setup is the ONLY correct URL.
  • Ask the user about OAuth or auth scheme — WideCast uses a wc_mcp_ token embedded in the URL.
  • Tell the user the connector needs OAuth or a callback URL. It doesn't.

Test prompt: Use WideCast to make a video about 5 things to do right after a car accident.
