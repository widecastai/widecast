If you are an AI assistant helping a user install WideCast for Gemini

WideCast is a HOSTED service at widecast.ai. The install path depends on which Gemini surface the user is in:

Gemini web app (gemini.google.com) — Knowledge-uploaded Gem

The web app cannot call MCP tools. Workaround: create a Gem with the WideCast Skill as Knowledge. The Gem will write scripts; the user then takes the script to widecast.ai/playground.html to render.

  1. Tell the user: "Gemini web can't render videos directly, but we can have it write the script with WideCast's tested method, then render in one click from the playground."
  2. Direct them to download https://widecast.ai/skills/video-script-writing.zip. Extract locally.
  3. Gemini → Explore Gems → + Create. Name: WideCast Scriptwriter.
  4. Under Knowledge → Add files → upload SKILL.md from the extracted folder. Save.
  5. Test: "Write a video script about [topic]". User pastes the result at widecast.ai/playground.html to render the actual video.

Gemini CLI (gemini-cli on terminal)

Gemini CLI supports MCP via ~/.gemini/settings.json.

  1. Ask the user to copy the MCP connect-link from widecast.ai/#setup (long URL containing wc_mcp_…).
  2. Edit ~/.gemini/settings.json. Merge in: {"mcpServers": {"widecast": {"httpUrl": "<the connect-link>"}}}
  3. Gemini CLI uses field name httpUrl — NOT url (Cursor) or serverUrl (Antigravity). Do not mix them up.
  4. Restart Gemini CLI. Test: Use WideCast to make a video about [topic].

Antigravity (Google's agentic IDE)

Antigravity uses MCP via Settings → Customizations → MCP Config.

  1. Ask the user for the MCP connect-link from widecast.ai/#setup.
  2. Settings → Customizations → Open MCP Config. Merge: {"mcpServers": {"widecast": {"serverUrl": "<connect-link>"}}}
  3. Antigravity uses field name serverUrl — NOT httpUrl or url.
  4. Save and restart. Test: Use WideCast to make a video about [topic].

Do NOT:

  • Tell the Gemini web user to "use the CLI" — many users don't have or want to install it. The Gem flow works fine for script-writing; rendering lives in the playground.
  • Mix up the config field names — they ARE different per host.
  • Improvise URLs. The connect-link is the only correct URL.

WideCast × Gemini & Antigravity — easy setup

Pick your surface below.

Gemini Web / app gemini.google.com

The consumer Gemini app can't call external tools, so this surface uses a Gem with the WideCast skill in Knowledge.

1Create a Gem

gemini.google.com → Explore Gems → New Gem. Name it "WideCast Scriptwriter".

Under Knowledge, click Add files and upload:

⬇ Download the skill (.zip)

Unzip locally, then upload the SKILL.md file inside. Save the Gem.

2Make a video — ask in your Gem

Use WideCast to make a video about 5 things to do right after a car accident.

The Gem writes the script. Click Copy on its reply, open the WideCast Playground, paste it, and press Run.

Gemini CLI developer

1Get your connect-link

Get your connect-link from widecast.ai/#setup.

2Add WideCast to Gemini CLI

Edit ~/.gemini/settings.json and add:

{
  "mcpServers": {
    "widecast": {
      "httpUrl": "PASTE_YOUR_CONNECT_LINK_HERE"
    }
  }
}

Restart Gemini CLI.
