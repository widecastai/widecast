The closed loop

From zero to ten platforms. Autonomously.

Most AI tools stop at generation. WideCast closes the whole circle — every input becomes finished, publishable content (a video, a blog post, or a social post — each with its own visuals) and posts itself to every platform you've connected. Script & scenes in between are the production stage: review, record, or hand off to an AI avatar.

Production-grade by design

Quickstart

Hello, video — from your agent.

from widecast import WideCast

wc = WideCast(api_key="wc_live_REPLACE_ME")

job = wc.create_video(
    source="idea",
    idea_text="why founders should ship on day one",
    output_type="video",
)

# async by default — poll for status
status = wc.status(job.id)   # GET /v1/status/{id}
print(status.state)          # queued → producing → ready
import { WideCast } from "@widecast/sdk";

const wc = new WideCast({ apiKey: "wc_live_REPLACE_ME" });

const job = await wc.createVideo({
  source: "idea",
  ideaText: "why founders should ship on day one",
  outputType: "video",
});

// async by default — poll for status
const status = await wc.status(job.id); // GET /v1/status/{id}
console.log(status.state);              // queued → producing → ready
{
  "tool": "widecast.create_video",
  "arguments": {
    "source": "idea",
    "idea_text": "why founders should ship on day one",
    "output_type": "video"
  }
}
// → { "id": "vid_8f3a", "state": "queued" }
// then: widecast.status { "id": "vid_8f3a" }
curl -X POST https://api.widecast.ai/v1/create_video \
  -H "Authorization: Bearer wc_live_REPLACE_ME" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "idea",
    "idea_text": "why founders should ship on day one",
    "output_type": "video"
  }'

# then poll:
curl https://api.widecast.ai/v1/status/vid_8f3a \
  -H "Authorization: Bearer wc_live_REPLACE_ME"

…then close the loop — create, (optionally) review, publish:

Python 
video = wc.create_video(source="idea",
                        idea_text="why founders should ship on day one",
                        output_type="video").wait()

print(video.review_url)        # 5% you — the human checkpoint

video.approve()                # looks good
video.publish(accounts=["tiktok", "youtube", "instagram", "x", "linkedin"])

Why agents love it

Agent-native, not bolted on.

⌘

One spec, self-describing

OpenAPI 3.1 + JSON Schema. Agents generate their own tools from /openapi.json.

↻

Async by default

POST then poll /v1/status/{id}, or subscribe to an HMAC-signed webhook.

⚠

Errors agents can act on

Structured envelope: type / code / doc_url / request_id.

⟳

Idempotent & safe to retry

Send an Idempotency-Key and we dedupe — retries never double-charge.

Apache-2.0 open source OpenAPI 3.1 spec HMAC-signed webhooks Idempotent by design AI-content disclosure built in Status & 99.9% uptime planned
