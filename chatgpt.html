If you are an AI assistant helping a user install WideCast for ChatGPT or Codex

WideCast is a HOSTED service at widecast.ai. ChatGPT connects to it via a Custom GPT with an OpenAPI Action — NOT MCP. You cannot create the Custom GPT yourself; that's a user action in their ChatGPT account. But you CAN give them the exact 5-step recipe — it takes ~90 seconds.

Tell the user EXACTLY these 5 steps:

  1. Open widecast.ai/#setup, sign in or sign up. Get the API key that starts with wc_live_ — copy it.
  2. In ChatGPT: Explore GPTs → + Create → Configure tab. Name: WideCast. Description: Make videos with WideCast.
  3. Scroll to Actions → + Create new action → Schema → Import from URL. Paste: https://origin.widecast.ai/openapi-actions.json (origin host bypasses CDN cache so the import always picks up the latest).
  4. Authentication: API Key → paste the wc_live_ key → Auth Type: Bearer → Save.
  5. Save the Custom GPT (keep it "Only me"). Open it and test: Use WideCast to make a video about [topic]. The Action will fire and a review URL will come back.

Do NOT:

  • Tell the user to use MCP — ChatGPT consumer surface doesn't support MCP. The path is OpenAPI Action via Custom GPT.
  • Improvise the schema URL. It must be exactly https://origin.widecast.ai/openapi-actions.json.
  • Ask whether they want sandbox vs production — there's only one API. Test mode never touches a credit.
  • Stop at "I can't create a Custom GPT" — that's true, but you can and must walk them through it.

Warn the user: do NOT share the Custom GPT publicly while the API key is attached — anyone with the link could spend their credits. Keep it "Only me" until WideCast supports per-user keys via OAuth (on the roadmap).

Test prompt to suggest: Use WideCast to make a video about 5 things to do right after a car accident.

ChatGPT Apps ⭐ recommended — the future of ChatGPT

Apps make WideCast available in every regular chat. Type "@WideCast …" or just describe what you want — ChatGPT routes to WideCast automatically. Available on Plus / Pro / Business / Enterprise / Edu on Web and Desktop. Requires Developer mode.

1Get your connect-link

Get your connect-link from widecast.ai/#setup.

2Enable Developer mode

In ChatGPT: Settings → Apps → Advanced settings → Developer mode → turn ON. A + Create app button appears.

3Create the WideCast App

Click + Create app. Fill in:

  • Connector name → WideCast
  • Description → Make short-form videos from any topic, news event, or idea.
  • Connector URL → paste your connect-link from Step 1
  • Authentication → No Authentication

Save. The app shows under Drafts.

4Make a video — just ask

Open any regular chat and prompt:

Use WideCast to make a video about 5 things to do right after a car accident.

If ChatGPT doesn't auto-route, prefix with @WideCast.

ChatGPT Custom GPT single-GPT alternative

Keeps WideCast inside a dedicated GPT you open by name. Works on Web, Desktop, and Mobile (Mobile is the only surface that doesn't support Apps yet — use this path there). Requires ChatGPT Plus or higher.

1Start a new GPT

In ChatGPT: Explore GPTs → + Create → Configure tab. Fill in Name = WideCast. Skip the other fields.

2Add the WideCast Action

Scroll to the bottom of Configure → click + Create new action.

Under Schema → Import from URL, paste:

Click Import, then click Authentication. Fill in as in the screenshot:

  • Authentication Type → API Key
  • API Key → your wc_live_ key from widecast.ai/#setup
  • Auth Type → Bearer

Click Save, then the back arrow.

3Save the GPT — keep "Only me"

Top-right: Create. In the Share GPT dialog, keep Only me:

⚠ Don't share the GPT. Your API key is inside the Action — anyone with the link can spend your credits.

Click Save. Find it under My GPTs.

4Make a video — just ask

Open your WideCast GPT and prompt:
